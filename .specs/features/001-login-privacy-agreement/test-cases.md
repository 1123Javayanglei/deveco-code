## 需求 FR-001: 登录状态检查

**需求描述**: 系统在用户打开 CLI 时检查是否已登录华为账号，已登录跳转协议检查，未登录显示登录页面

### 正向场景（必选）

- [ ] **TC-FR001-001**: 已登录用户跳过登录页面
  - **前置条件**: 用户已通过 DevEcoAuth 登录华为账号，token 有效
  - **测试步骤**:
    1. 启动 CLI
    2. 系统调用 DevEcoAuth.isLoggedIn() 返回 true
    3. 系统跳过登录页面，直接进入协议签署状态检查
  - **预期结果**: 已登录用户不看到登录页面，直接进入协议检查流程
  - **验证状态**: ⏳ 待验证

- [ ] **TC-FR001-002**: 未登录用户显示登录页面
  - **前置条件**: 用户未登录华为账号
  - **测试步骤**:
    1. 启动 CLI
    2. 系统调用 DevEcoAuth.isLoggedIn() 返回 false
    3. 系统显示登录引导页面
  - **预期结果**: 未登录用户看到登录页面，提供"登录"和"不登录"选项
  - **验证状态**: ⏳ 待验证

## 需求 FR-003: 协议签署状态远程查询

**需求描述**: 已登录用户调用华为 TMS API 查询协议签署状态和版本信息

### 正向场景（必选）

- [ ] **TC-FR003-001**: 用户已签署最新版本协议，查询返回合规
  - **前置条件**: 用户已登录，已签署最新版本协议
  - **测试步骤**:
    1. 系统调用 TMS 协议查询 API（nsp_svc=as.user.query）
    2. API 返回 errorCode=0，signInfo 非空，isAgree=true
    3. versionInfo[0].newestVersion <= signInfo[0].version
    4. 系统判定为合规，直接进入对话页面
  - **预期结果**: 用户直接进入对话页面，无需额外操作
  - **验证状态**: ⏳ 待验证

- [ ] **TC-FR003-002**: 用户未签署协议，查询返回需要签署
  - **前置条件**: 用户已登录，未签署隐私协议
  - **测试步骤**:
    1. 系统调用 TMS 协议查询 API
    2. API 返回 signInfo 为空 或 isAgree=false
    3. 系统判定需要签署，显示协议签署页面
  - **预期结果**: 系统显示协议签署页面
  - **验证状态**: ⏳ 待验证

### 边界场景（可选）

- [ ] **TC-FR003-EDGE-001**: 用户已签署但版本低于最新版本
  - **前置条件**: 用户已登录，已签署旧版本协议
  - **测试步骤**:
    1. 系统调用 TMS 协议查询 API
    2. API 返回 isAgree=true，但 signedVersion < newestVersion
    3. 系统判定需要重新签署
  - **预期结果**: 系统显示协议签署页面，提示用户需要签署最新版本
  - **验证状态**: ⏳ 待验证 / ⏭️ 跳过

## 需求 FR-007: Session 超时重试

**需求描述**: API 调用因 session 超时失败时，自动刷新 token 并重试

### 正向场景（必选）

- [ ] **TC-FR007-001**: 协议查询 session 超时后自动刷新 token 重试成功
  - **前置条件**: 用户已登录，协议查询 API 返回 SESSION_TIMEOUT 错误
  - **测试步骤**:
    1. 系统调用协议查询 API
    2. API 返回 error=SESSION_TIMEOUT
    3. 系统调用 DevEcoAuth.refreshToken() 刷新 token
    4. 刷新成功，getLoginFlag=true
    5. 使用新 token 重试协议查询 API
    6. 重试成功，正常返回签署状态
  - **预期结果**: 自动重试后成功获取签署状态
  - **验证状态**: ⏳ 待验证

- [ ] **TC-FR007-002**: 协议签署 session 超时后自动刷新 token 重试成功
  - **前置条件**: 用户已点击 Agree，签署 API 返回 SESSION_TIMEOUT 或 INVALID_SESSION
  - **测试步骤**:
    1. 系统调用签署 API
    2. API 返回 SESSION_TIMEOUT 或 INVALID_SESSION
    3. 系统调用 refreshToken() 刷新 token
    4. 使用新 token 重试签署 API
    5. 重试成功，errorCode=0
  - **预期结果**: 签署成功
  - **验证状态**: ⏳ 待验证

### 异常场景（可选）

- [ ] **TC-FR007-ERR-001**: token 刷新失败后不再重试
  - **前置条件**: API 返回 SESSION_TIMEOUT，且 refreshToken 失败（getLoginFlag=false）
  - **测试步骤**:
    1. 系统调用协议查询/签署 API
    2. API 返回 SESSION_TIMEOUT
    3. 系统调用 refreshToken()
    4. 刷新失败，getLoginFlag=false
    5. 系统不重试，返回需要签署/签署失败
  - **预期结果**: 返回失败结果，不修改本地缓存
  - **验证状态**: ⏳ 待验证 / ⏭️ 跳过

    1. 签署 API 返回非 session 超时错误
