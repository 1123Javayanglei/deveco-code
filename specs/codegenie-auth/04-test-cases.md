## 需求 FR-002: JWT Token 安全存储

**需求描述**: 登录成功后获取 JWT Token 并使用 AES-128-GCM 加密存储

### 正向场景（必选）

- [ ] **TC-FR002-001**: Token 加密存储验证
  - **前置条件**: 已完成 CodeGenie OAuth 登录
  - **测试步骤**:
    1. 检查 `~/.config/codegenie/token.enc` 文件存在
    2. 检查 `~/.config/codegenie/.token_key` 文件存在
    3. 检查 `token.enc` 文件内容为加密 JSON（包含 encrypted, iv, authTag 字段）
    4. 检查文件权限为 0600
  - **预期结果**: Token 以 AES-128-GCM 加密存储，文件权限正确
  - **验证状态**: ⏳ 待验证

### 边界场景（可选）

- [ ] **TC-FR002-EDGE-001**: Token 文件损坏后恢复
  - **前置条件**: 已登录，Token 文件存在
  - **测试步骤**:
    1. 手动修改 `token.enc` 文件内容为无效数据
    2. 重启 TUI
  - **预期结果**: Token 加载失败时自动清除损坏文件，显示引导界面
  - **验证状态**: ⏳ 待验证 / ⏭️ 跳过
