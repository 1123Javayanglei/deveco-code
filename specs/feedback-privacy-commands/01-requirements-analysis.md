# 需求分析说明书: /feedback 与 /privacy 斜杠命令

**功能分支**: `feedback-privacy-commands`
**创建日期**: 2026-04-21
**状态**: 草稿
**输入**: 将 /feedback 和 /privacy 斜杠命令从 codegenie-old 迁移到 codegenie-cli

---

## 1. 简介

### 1.1 目的

本文档对 `/feedback` 和 `/privacy` 两个斜杠命令进行需求分析，明确功能范围、用户场景和系统影响，指导后续功能设计与实现。

### 1.2 范围

**包含**：
- `/feedback` 命令：在 TUI 中提供反馈入口，打开华为开发者反馈页面
- `/privacy` 命令：在 TUI 中提供隐私政策查看入口，打开华为隐私政策页面
- 命令面板（Command Palette）中的命令展示与触发
- 斜杠命令自动补全支持

**不包含**：
- 反馈内容的收集、存储与处理
- 隐私政策页面本身的内容维护
- 非 TUI 环境（如 CLI 直接调用、API）下的命令支持

### 1.3 假设和约束

| 类型 | 描述 |
|------|------|
| 假设 | 目标用户的运行环境支持通过 `open()` 函数打开浏览器 |
| 假设 | 华为开发者反馈页面和隐私政策页面的 URL 保持稳定 |
| 假设 | `sync.data.provider_next.connected` 可准确反映当前 CodeGenie 用户的登录状态 |
| 约束 | `/privacy` 命令仅对 CodeGenie provider 登录用户可见，需通过 provider 连接状态判断 |
| 约束 | 命令需在 TUI 的命令注册体系中实现，复用现有的 `useCommandDialog` 机制 |

### 1.4 术语与缩写

| 术语/缩写 | 全称 | 说明 |
|-----------|------|------|
| TUI | Terminal User Interface | 终端用户界面 |
| Slash Command | 斜杠命令 | 以 `/` 开头的用户指令，在 TUI 输入框中触发 |
| Command Palette | 命令面板 | 通过快捷键唤起的命令选择列表 |
| Provider | 服务提供者 | AI 模型服务提供商（如 codegenie、anthropic 等） |
| sync | 同步状态 | TUI 上下文中维护的全局同步状态对象 |

## 2. 系统上下文

### 2.1 系统定位

`/feedback` 和 `/privacy` 是 codegenie-cli TUI 的系统级斜杠命令，归属于 "System" 类别。它们位于 TUI 命令注册体系的最末端，为用户提供产品反馈入口和隐私政策查看入口。

### 2.2 系统边界

```
┌─────────────────────────────────────────┐
│            codegenie-cli TUI            │
│                                         │
│  ┌─────────────┐   ┌────────────────┐  │
│  │ 用户输入    │──▶│ 命令检测/补全  │  │
│  │ /feedback   │   │ autocomplete   │  │
│  │ /privacy    │   └───────┬────────┘  │
│  └─────────────┘           │            │
│                            ▼            │
│                  ┌─────────────────┐    │
│                  │ 命令注册表       │    │
│                  │ command.register│    │
│                  └────────┬────────┘    │
│                           │             │
│                           ▼             │
│                  ┌─────────────────┐    │
│                  │ open() 打开URL  │────┼──▶ 华为开发者反馈页面
│                  └─────────────────┘    │
│                           │             │
│                           ▼             │
│                  ┌─────────────────┐    │
```

## 3. 需求分析概述

### 3.1 需求来源

- **产品需求**：codegenie-old 已实现 /feedback 和 /privacy 命令，需要迁移至 codegenie-cli
- **合规需求**：隐私政策入口是应用合规的基本要求，CodeGenie 登录用户需能便捷访问隐私政策
- **用户需求**：用户需要统一的反馈提交入口

### 3.2 需求目标

1. 为所有 codegenie-cli 用户提供便捷的产品反馈入口
2. 为 CodeGenie 登录用户提供隐私政策查看入口
3. 命令通过命令面板和斜杠命令两种方式触发

### 3.3 关键利益相关者

| 角色 | 职责 | 关注点 |
|------|------|--------|
| CodeGenie 产品用户 | 使用 CLI 工具进行开发 | 反馈入口是否便捷、隐私政策是否可访问 |
| CodeGenie 平台运营 | 接收用户反馈 | 反馈页面是否能正确打开 |
| 合规团队 | 监督隐私合规 | 隐私政策入口是否对所有 CodeGenie 用户可见 |
| 开发者 | 实现和维护命令 | 代码改动量、与现有命令体系的兼容性 |

## 4. 需求场景分析

### 4.1 业务场景

#### 4.1.1 业务流程图

```
用户触发命令
    │
    ├── 通过命令面板选择 ──▶ onSelect 回调
    │
    └── 通过斜杠命令输入 ──▶ TUI 检测 "/" ──▶ 命令匹配 ──▶ onSelect 回调
                                                                    │
                                                                    ▼
                                                         open(url) 打开浏览器
                                                                    │
                                                                    ▼
                                                              dialog.clear()
```

#### 4.1.2 业务规则

| 规则编号 | 规则名称 | 规则描述 | 优先级 |
|----------|----------|----------|--------|
| BR-001 | 反馈命令无条件可见 | /feedback 对所有用户可见，无需登录状态判断 | 高 |
| BR-002 | 隐私命令条件可见 | /privacy 仅在 CodeGenie provider 连接成功时显示 | 高 |
| BR-003 | URL打开失败静默处理 | 若 open() 调用失败（如无浏览器），静默处理不报错 | 中 |

### 4.2 用户操作场景与关键路径

#### 4.2.1 用户角色定义

| 角色ID | 角色名称 | 角色描述 | 权限范围 |
|--------|----------|----------|----------|
| UR-001 | 普通用户 | 未通过 CodeGenie provider 登录的用户 | 可使用 /feedback |
| UR-002 | CodeGenie 用户 | 通过 CodeGenie provider 登录的用户 | 可使用 /feedback 和 /privacy |

#### 4.2.2 用户操作场景

**场景 US-001: 通过斜杠命令提交反馈** (优先级: P1)

| 项目 | 描述 |
|------|------|
| 场景描述 | 用户在 TUI 输入框中输入 `/feedback` 触发反馈命令 |
| 前置条件 | 用户已启动 codegenie-cli TUI |
| 操作步骤 | 1. 用户在输入框输入 `/feedback`<br>2. 系统匹配到 feedback 命令<br>3. 系统调用 `open()` 打开反馈页面<br>4. 关闭命令面板 |
| 预期结果 | 浏览器打开华为开发者反馈页面 |
| 异常处理 | open() 失败时静默忽略，不影响 TUI 正常使用 |

**场景 US-002: 通过命令面板提交反馈** (优先级: P1)

| 项目 | 描述 |
|------|------|
| 场景描述 | 用户通过命令面板选择 Feedback 命令 |
| 前置条件 | 用户已启动 codegenie-cli TUI |
| 操作步骤 | 1. 用户打开命令面板<br>2. 在 System 类别下找到 "Feedback" 命令<br>3. 选择并执行该命令 |
| 预期结果 | 浏览器打开华为开发者反馈页面，命令面板关闭 |
| 异常处理 | open() 失败时静默忽略 |

**场景 US-003: CodeGenie 用户查看隐私政策** (优先级: P1)

| 项目 | 描述 |
|------|------|
| 场景描述 | CodeGenie 登录用户通过斜杠命令或命令面板查看隐私政策 |
| 前置条件 | 用户已通过 CodeGenie provider 成功登录 |
| 操作步骤 | 1. 用户输入 `/privacy` 或在命令面板选择 "Privacy"<br>2. 系统验证用户已连接 CodeGenie provider<br>3. 打开华为隐私政策页面 |
| 预期结果 | 浏览器打开华为隐私政策页面 |
| 异常处理 | open() 失败时静默忽略 |

**场景 US-004: 非 CodeGenie 用户无法看到隐私命令** (优先级: P2)

| 项目 | 描述 |
|------|------|
| 场景描述 | 未登录 CodeGenie 的用户无法看到 /privacy 命令 |
| 前置条件 | 用户未连接 CodeGenie provider |
| 操作步骤 | 1. 用户打开命令面板<br>2. 浏览 System 类别命令列表 |
| 预期结果 | 列表中不显示 "Privacy" 命令 |
| 异常处理 | 无 |

### 4.3 兼容性分析

#### 4.3.1 平台兼容性

| 平台 | 兼容性要求 | 备注 |
|------|------------|------|
| macOS | `open()` 使用系统默认浏览器 | 主要目标平台 |
| Windows | `open()` 使用系统默认浏览器 | 主要目标平台 |
| Linux | `open()` 使用 xdg-open | 非 primary 目标平台 |

## 5. 功能性需求分析

### 5.1 功能需求列表

| 需求编号 | 需求名称 | 需求描述 | 优先级 | 来源 |
|----------|----------|----------|--------|------|
| FR-001 | Feedback 命令注册 | 在 TUI 命令注册表中添加 Feedback 命令项，支持命令面板和斜杠命令触发 | P1 | 产品需求 |
| FR-002 | Feedback URL 打开 | 点击或触发 /feedback 时，使用 open() 打开华为开发者反馈页面 URL | P1 | 产品需求 |
| FR-003 | Privacy 命令注册 | 在 TUI 命令注册表中添加 Privacy 命令项，支持命令面板和斜杠命令触发 | P1 | 合规需求 |
| FR-004 | Privacy 条件可见 | Privacy 命令仅在 sync.data.provider_next.connected 包含 "codegenie" 时显示 | P1 | 合规需求 |
| FR-005 | Privacy URL 打开 | 触发 /privacy 时，使用 open() 打开华为隐私政策页面 URL | P1 | 合规需求 |
| FR-006 | 自动补全支持 | /feedback 和 /privacy 在斜杠命令自动补全列表中可见 | P2 | 用户体验 |

### 5.2 功能需求详细说明

#### FR-001: Feedback 命令注册

| 项目 | 描述 |
|------|------|
| 需求描述 | 系统必须在 TUI 命令注册表中注册一个 "Feedback" 命令，标题为 "Feedback"，描述为 "Submit complaints, suggestions or feedback"，值为 "feedback.open"，支持 `/feedback` 斜杠命令，归类为 "System" 类别 |
| 验收标准 | 1. 命令面板 System 类别下可见 "Feedback" 项<br>2. 输入 `/feedback` 可触发该命令 |
| 关联场景 | US-001, US-002 |

#### FR-004: Privacy 条件可见

| 项目 | 描述 |
|------|------|
| 需求描述 | 系统必须根据 `sync.data.provider_next.connected.includes("codegenie")` 的结果决定是否在命令列表中包含 Privacy 命令。当结果为 false 时，命令列表中不应出现任何 Privacy 相关条目 |
| 验收标准 | 1. CodeGenie 登录用户可见 Privacy 命令<br>2. 非 CodeGenie 用户不可见 Privacy 命令 |
| 关联场景 | US-003, US-004 |

### 5.3 功能依赖关系

| 需求ID | 依赖需求 | 依赖类型 | 说明 |
|--------|----------|----------|------|
| FR-002 | FR-001 | 强依赖 | URL 打开依赖命令注册的 onSelect 回调 |
| FR-005 | FR-003 | 强依赖 | URL 打开依赖命令注册的 onSelect 回调 |
| FR-006 | FR-001, FR-003 | 弱依赖 | 自动补全从已注册命令的 slash 字段自动生成 |

## 6. 非功能性需求分析

### 6.1 定位

目标用户群体为使用 codegenie-cli TUI 的开发者，需要快速访问产品反馈和隐私政策页面。

### 6.2 系统可靠性

| 指标 | 要求 | 说明 |
|------|------|------|
| 命令可用性 | 100% | 命令注册不依赖外部服务，始终可用（Privacy 受登录状态约束） |
| URL 打开容错 | 静默失败 | open() 失败时不影响 TUI 运行 |

### 6.3 安全隐私

| 安全类型 | 需求描述 | 安全等级 |
|----------|----------|----------|
| URL 安全 | 仅打开预定义的华为官方 URL，不接受用户输入 | 低 |

### 6.4 可测试性

| 测试类型 | 测试要求 | 覆盖率目标 |
|----------|----------|------------|
| 单元测试 | 验证命令注册列表包含 feedback 和 privacy 项 | 关键路径 100% |
| 集成测试 | 验证条件渲染：未连接 codegenie 时 privacy 不可见 | 关键路径 100% |

## 7. 系统影响分析

### 7.1 功能影响列表

| 影响模块 | 影响类型 | 影响程度 | 影响描述 |
|----------|----------|----------|----------|
| `app.tsx` (TUI 主组件) | 修改 | 低 | 在 command.register() 调用末尾追加两个命令项 |

### 7.2 风险评估与缓解措施

| 风险项 | 风险等级 | 影响范围 | 缓解措施 |
|--------|----------|----------|----------|
| open() 在某些环境不可用 | 低 | URL 无法打开 | 已有 .catch(() => {}) 静默处理 |
| 华为页面 URL 变更 | 低 | 命令打开错误页面 | URL 硬编码，变更时需同步修改代码 |
